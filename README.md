A MuJoCo scene with three UFactory Lite 6 robots on a 60 inch by 30 inch workstation clipping red and blue cables on a fixture through a grey box.

## Run on Linux station in Lab:
First 
cd gerry_DLO

Run headless:

```bash
/home/nasta/miniconda3/bin/conda run -n ros_noetic python3 run_dlo.py
```

Open the interactive viewer:

```bash
/home/nasta/miniconda3/bin/conda run -n ros_noetic python3 run_dlo.py --view
```
